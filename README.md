# Material Stock Manager

資材コードを正とした在庫管理Webアプリ。OCRで資材コードを読み取り、入庫・出庫・在庫確認・履歴管理を行います。

## 技術スタック

- **フロントエンド**: Next.js 14 (App Router), React, TypeScript, Tailwind CSS
- **バックエンド**: Next.js API Routes
- **DB**: SQLite + Prisma ORM
- **OCR**: Tesseract.js (ブラウザサイド処理)
- **CSV出力**: サーバーサイド生成

## セットアップ手順

### 必要環境

- Node.js 18 以上
- npm

### 手順

```bash
# 1. リポジトリのクローン / ディレクトリ移動
cd inventory-management

# 2. 依存パッケージのインストール
npm install

# 3. データベースのマイグレーション
npx prisma migrate dev --name init

# 4. シードデータ投入
npx tsx prisma/seed.ts

# 5. 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

## Prismaマイグレーション

```bash
# スキーマ変更後にマイグレーションを作成・適用
npx prisma migrate dev --name <migration_name>

# Prisma Studio (DBビューア) を起動
npm run db:studio

# DBをリセットしてシードを再投入
npm run db:reset
```

サンプルデータ（MAT-001〜MAT-005）を投入します。

```bash
npx tsx prisma/seed.ts
```

|-----------|--------|-----------|--------|
| MAT-001 | 検査キット外箱 | 使用中 | 120 |
| MAT-002 | 検査キット外箱（改訂版） | 移行中 | 80 |
| MAT-003 | 説明書 | 使用中 | 300 |

## OCR機能の使い方

1. ナビゲーションの「OCR読込」をクリック
2. 「ファイルを選択」または「カメラで撮影」で画像を選択
3. 「OCRを実行する」をクリック
4. OCR読み取り結果が表示される
5. **必ず**資材コード入力欄で内容を確認・補正する
6. 「検索」ボタンで資材マスタと照合
7. 資材情報を確認して「入庫」または「出庫」に進む

> ⚠ OCR結果は参考情報です。1文字の誤認識で別資材になる場合があるため、必ず資材情報を確認してから処理を確定してください。

## 入庫の使い方

1. 「入庫登録」画面を開く
2. 資材コードを入力して「検索」
3. 資材情報を確認（ステータス・現在庫に注意）
4. 入庫数量・理由・備考を入力
5. 確認エリアで処理内容を確認
6. 「入庫を確定する」をクリック

## 出庫の使い方

1. 「出庫登録」画面を開く
2. 資材コードを入力して「検索」
3. 資材情報と現在庫を確認
4. 出庫数量・理由・使用先・備考を入力（現在庫超過は不可）
5. 確認エリアで処理内容を確認
6. 「出庫を確定する」をクリック

## CSV出力

| 画面 | 出力内容 |
|------|---------|
| 資材マスタ一覧 | 資材マスタ全項目 |
| 在庫一覧 | 現在庫・ステータス一覧 |
| 入出庫履歴 | 全履歴（処理前後在庫含む） |

各画面の検索・絞り込み条件を適用した状態でCSV出力できます。
